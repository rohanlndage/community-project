Learn how computers process code, problem-solving logic, flowcharts, pseudocode, and core programming building blocks.

Key Topics Covered:

  • What is Programming & Algorithmic Thinking
  • Variables, Constants & Data Types (Integer, Float, String, Boolean)
  • Input / Output Operations & Formatting
  • Control Statements: if, if-else, switch-case
  • Loops & Iteration: for, while, do-while
  • Functions, Scope & Modularity

2. HTML (HyperText Markup Language)

Understand web page construction, markup elements, attributes, forms, and modern semantic HTML5 standards.

Key Topics Covered:

  • HTML Document Skeleton (<!DOCTYPE html>, <head>, <body>)
  • Headings, Paragraphs, Text Formatting & Lists
  • Hyperlinks (<a href="...">) & Media Tags (<img>, <video>, <audio>)
  • HTML Tables & Form Elements (Inputs, Labels, Buttons, Textarea)
  • Semantic Tags: <header>, <nav>, <main>, <section>, <footer>
Read Full Notes

3. CSS (Cascading Style Sheets)

Master web layout styling, responsive design rules, colors, typography, Flexbox, and CSS Grid layouts.

Key Topics Covered:

  • CSS Syntax, Selectors (Element, Class, ID, Attribute, Pseudo-classes)
  • The Box Model (Margin, Border, Padding, Content)
  • Positioning (`static`, `relative`, `absolute`, `fixed`, `sticky`)
  • Flexbox Layout Architecture (flex-direction, justify-content, align-items)
  • CSS Grid System (grid-template-columns, gap)
  • Media Queries & Responsive Web Design
Read Full Notes

4. JavaScript

Bring web pages to life with client-side interactivity, DOM manipulation, events, and modern ES6 features.

Key Topics Covered:

  • JavaScript Syntax, var vs let vs const
  • DOM Selection & Element Manipulation (querySelector, innerHTML, classList)
  • Event Handling (addEventListener, Click, Input, Form Submit)
  • ES6+ Features: Arrow functions, Template Literals, Destructuring, Spread operator
  • Asynchronous JavaScript: Callbacks, Promises, async/await, fetch() API
Read Full Notes

5. C / C++ Fundamentals

Build strong core programming logic, understand low-level pointers, structures, and Object-Oriented concepts.

Key Topics Covered:

  • C & C++ Syntax, Compiler Flow & Header Files
  • Pointers, References & Dynamic Memory Allocation (`malloc`, `free`, `new`, `delete`)
  • Structures (`struct`), Unions & Enums
  • OOP Principles: Classes, Objects, Inheritance, Polymorphism, Encapsulation
  • C++ Standard Template Library (STL): Vectors, Maps, Sets, Stacks
Read Full Notes

6. Python Programming

Learn Python's clean syntax, versatile built-in data structures, object-oriented design, and practical scripting.

Key Topics Covered:

  • Python Data Types, Strings & Indentation Syntax
  • Collections: Lists, Tuples, Dictionaries, Sets
  • List Comprehensions & Lambda Functions
  • File Handling (Reading/Writing Files) & Exception Handling
  • Object-Oriented Python (Classes, `__init__`, Methods, Inheritance)
Read Full Notes

7. Java Fundamentals

Master Java platform independence, JVM execution, Object-Oriented Principles, and the Collections Framework.

Key Topics Covered:

  • Java Virtual Machine (JVM), JDK, JRE Architecture
  • Core Syntax, Data Types & Wrapper Classes
  • OOPs Concepts: Inheritance, Polymorphism, Abstraction, Interfaces
  • Exception Handling (`try-catch-finally`, Custom Exceptions)
  • Java Collections Framework (ArrayList, HashMap, HashSet, LinkedList)

8. Data Structures & Algorithms (DSA)

Develop advanced problem-solving techniques, time/space complexity evaluation, data structures, and algorithmic patterns.

Key Topics Covered:

  • Big-O Notation, Time & Space Complexity Analysis
  • Linear Structures: Arrays, Strings, Linked Lists, Stacks, Queues
  • Searching Algorithms (Linear Search, Binary Search)
  • Sorting Algorithms (Bubble, Selection, Insertion, Merge, Quick Sort)
  • Non-Linear Structures: Trees, Binary Search Trees, Graphs, Hashing
